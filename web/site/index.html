the idea

Agents don't fail with a stack trace. They fail by quietly doing something different. agentdiff makes that difference visible.

how it works

Three views onto the same runs.

Record traces, see them as a shape, and pull any two apart step by step. One vocabulary, no dashboards to assemble.

01

Path graph

Every run of a task, merged into one network. Nodes are tool calls, edges are transitions, thickness is how many runs took that step. Strategies become shapes you can read at a glance.

02

Diff & triage

Two runs aligned step by step — match, substitute, insert, delete. An AI triage panel names the change: regression, variance, or additive, with the likely cause.

03

Transcript & scrubber

Inspect any single run up close. A step rail on the left scrubs through context, reasoning, tool calls and outputs on the right — the raw record behind the shape.

questions

Good to know.

A baseline is the set of runs for one task — "what good looks like." New runs are compared against it. When a run diverges from the baseline in a way that changes the outcome, that's the signal.

Assertion-based tests check a fixed expected output. Agents take many valid paths, so those tests are brittle and miss behavioral drift. agentdiff compares the path a run took against its baseline — no expected-output string to maintain.

Variance is different paths that reach the same outcome — usually healthy. A regression is a divergence that changes the outcome, like a dropped step that flips a routing decision. The triage panel makes that call and shows the likely cause.

Install the CLI and pipe runs through an adapter — LangChain, LlamaIndex, or raw JSON. You can also drag a trace file straight into the browser. No SDK rewrite required.

The demo runs on three seeded stories — code review, support triage, and docs generation — so you can see the product working before sending anything of your own. Everything you click is live.
