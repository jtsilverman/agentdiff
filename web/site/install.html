quickstart

Three steps to a baseline.

01

Install

Grab the CLI from npm. It ships the recorder and the local viewer.

# global install
npm i -g agentdiff
agentdiff login
02

Record runs

Wrap your agent invocation. Every tool call and result is captured as a trace.

import { record } from 'agentdiff'

await record('pr-review', () =>
  agent.run(task))
03

Diff & triage

After a few runs you have a baseline. New runs diff against it automatically.

agentdiff diff pr-review \
  --against baseline
# → variance · no regression
adapters

Bring traces from where they already live.

agentdiff reads the shape of a run, not your framework. Pipe in from the big two, or hand it raw JSON.

LangChain

callback handler
from agentdiff import Tracer
chain.run(input,
  callbacks=[Tracer("pr-review")])

LlamaIndex

instrumentation handler
from agentdiff import handler
Settings.callback_manager = \
  CallbackManager([handler()])

Raw JSON

any agent, any language
agentdiff push run.json \
  --baseline pr-review
