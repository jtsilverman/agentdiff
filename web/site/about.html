You probably landed here from a link, not a job board. So rather than a pitch: the thing you just clicked through — the path graph, the step-aligned diff, the AI triage that tells a regression from healthy variance — is the portfolio.

agentdiff exists because testing AI agents with brittle assertions doesn't work: agents take many valid paths to the same outcome. It records what an agent actually did, learns what good looks like for a task, and surfaces the moment a new run quietly diverges. The demo runs on seeded data so anyone can see it work in under five minutes.
